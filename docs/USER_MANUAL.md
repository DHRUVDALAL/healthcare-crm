# General User Manual

**System Title**: HealthCRM - Enterprise Healthcare Recruitment ERP + CRM  

---

## 1. Navigating the System

- **Dashboard**: Access real-time recruitment metrics, candidate pipeline statuses, and upcoming interviews.
- **Candidates**: Search candidate pool, upload resumes, and assign candidates to job requisitions.
- **Hospitals**: View client hospital contact details, active jobs, and placement billing histories.
- **Jobs**: Create job requisitions, set required qualifications, and run candidate matching.
- **Global Search (Ctrl + K)**: Instantly search across candidates, hospitals, jobs, employees, invoices, and tasks.
