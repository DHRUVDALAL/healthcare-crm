# Administrator Operations Manual

**System Title**: HealthCRM - Enterprise Healthcare Recruitment ERP + CRM  

---

## 1. Executive Operations Center

- **25-KPI Live Dashboard**: View real-time revenue, open jobs, active hospitals, placements, and employee productivity scores.
- **Employee RBAC Management**: Assign roles (`admin`, `recruiter`, `hr`, `finance`) and configure fine-grained module permissions.
- **Finance ERP & Invoicing**: Approve invoice drafts, review hospital ledgers, and track GST collection estimates.
- **Database Backup Engine**: Trigger manual database dumps and log backup history.
- **System Health Monitoring**: Monitor CPU usage %, RAM consumption MB, active user sessions, and server uptime.
