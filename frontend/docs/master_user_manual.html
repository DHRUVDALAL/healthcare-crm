SECTION 1: System Overview & Technical Architecture

1.1 Executive System Overview

HealthCRM Staffing is a specialized Healthcare Recruitment CRM, Agency ERP, and Workforce Management System engineered for medical staffing consultancies, hospitals, nursing agencies, and healthcare organizations. The platform automates the entire staffing pipeline from client hospital onboarding to candidate matching, PII-stripped corporate submission packages, multi-round interview scheduling, GST-compliant invoicing, employee payroll, attendance tracking, and leave management.

Embedded High-Availability Engine: HealthCRM Staffing features a pure WebAssembly (WASM) embedded SQLite database engine (sql.js) with debounced disk persistence, delivering 70-microsecond query speeds and guaranteeing 100% platform availability even during external database downtime or server deployments.

SECTION 2: Role-Based Access Control (RBAC) & Security Matrix

2.1 Dual Role Permission System

HealthCRM Staffing enforces a strict dual-role security framework dividing system users into Administrators and Employees. Access control is enforced across three distinct layers: Navigation Bar visibility, Frontend JS page protection, and Backend JWT API endpoint middleware.

SECTION 3: System Administrator Master Guide

3.1 Login & Authentication System (/pages/login.html)

User Authentication & Password Enforcement All Roles

Secure login portal with bcrypt hashed password verification, JWT token issuance, and password complexity enforcement.

Buttons & Actions:

  • Email Input: Enter registered email address (e.g. admin@crm.com).
  • Password Input: Enter account password.
  • Sign In Button: Validates credentials and redirects user to Dashboard.

3.2 Executive Dashboard (/pages/dashboard.html)

25-KPI Enterprise Control Center Administrator Role

Real-time analytics monitor covering Active Jobs, Pipeline Candidates, Placements, Total Revenue, Unpaid Invoices, and Pending Leaves.

Interactive Toolbar Buttons:

  • Quick Add: Opens multi-entity creation dialog for instant candidate, job, or hospital entry.
  • Refresh: Force re-syncs dashboard indicators with embedded database.
  • Date Filter: Toggles metrics by Today, This Week, This Month, or Year-to-Date.

3.3 Client Hospital ERP (/pages/hospitals.html)

Hospital Onboarding & Contract Management Administrator Role

Register healthcare clients, configure contract fee tiering (Tier A 10%, Tier B 8.33%, Tier C Fixed Fee), and track onboarding status.

Step-by-Step Hospital Onboarding:

  1. Click + Add Hospital.
  2. Enter Hospital Name, Address, Contact Person, Phone, and Email.
  3. Select Contract SLA Tier and Placement Fee Percentage.
  4. Set Status to Active and click Save Hospital.

3.4 Job Orders & Vacancy Management (/pages/jobs.html)

Posting Medical Job Openings Administrator Role

Create job orders assigned to onboarding hospitals (e.g. ICU Staff Nurse, Resident Doctor, Anaesthetist) with salary CTC specifications.

Form Fields & Actions:

  • + Post New Job: Launches job creation modal.
  • Hospital Client Select: Links vacancy to registered hospital.
  • Annual CTC Range: Establishes base billing amount for fee calculation.
  • Close Vacancy: Updates job status to Filled or Closed upon successful hiring.

3.5 Candidate Sourcing & PII-Stripped PDF Generator (/pages/applicants.html)

Candidate Management & PII Protection Administrator Role

Register candidates, record medical qualifications, track current vs. expected CTC, and generate GDPR/HIPAA compliant submission packages.

Generating PII-Stripped Corporate Submission Packages:

  1. Navigate to Candidate Profile or Applicants list.
  2. Click Download Submission Package.
  3. The engine strips candidate email, phone, and home address while preserving medical experience, qualifications, and notice period.
  4. A branded PDF package is instantly compiled for client hospital review.

3.6 Finance ERP & Placement Invoicing (/pages/invoices.html)

GST 18% Invoice Billing & Payment Ledger Administrator Role

Generate placement fee invoices upon candidate joining. Calculates fee percentages or fixed fees with automatic GST 18% tax breakdown.

Invoicing Buttons & Ledger Actions:

  • + Create Invoice: Opens modal form to select Hospital, Candidate, and Placement Fee %.
  • Record Payment: Enter payment amount, payment method (Bank Transfer, Cheque, UPI), transaction reference number, and payment date.
  • Download PDF: Downloads branded invoice PDF complete with agency bank details and GST ledger.

3.7 Employee Monthly Payroll (/pages/salary.html)

Monthly Payroll Processing & Payslip Generator Administrator Role

Process monthly salaries for recruiters and staff. Calculates base salary, bonuses, statutory deductions (Tax, PF, ESI), and Net Pay.

Payroll Steps:

  1. Click + Create Salary Record.
  2. Select Employee, Salary Month (YYYY-MM), Base Salary, Bonus, and Deductions.
  3. Click Save Record (Calculates Net Pay automatically).
  4. Click Mark as Paid when salary is disbursed.
  5. Click Download Payslip to generate corporate payslip PDF.

3.8 Admin Leave Approval & Rejection Center (/pages/leaves.html)

Reviewing Employee Leave Requests Administrator Role

Administrators have complete oversight of employee leave applications. Pending requests can be approved or rejected in one click.

Admin Actions:

  • Approve: One-click approval of employee leave request with automatic leave balance update.
  • Reject: One-click rejection of leave request.
  • Review: Opens modal form to append optional Admin Remarks explaining decision reasoning.

3.9 Platform Branding & Manual Database Backups (/pages/settings.html)

System Branding & Database Backups Administrator Role

Customize agency branding name, system logo mark, password enforcement rules, and create manual SQLite database backup snapshots.

Creating Manual Database Backup:

  1. Navigate to Settings → Database & System Health.
  2. Click Create Database Backup.
  3. The system generates a timestamped .sqlite file in /backend/backups/ and logs the backup event to system audit trail.

SECTION 4: Employee & Recruiter Workspace Operating Guide

4.1 Employee Restricted Workspace Rules

When logging in as a Recruitment Consultant or Employee, the system provides a clean, focused workspace tailored specifically for candidate sourcing, job matching, and leave tracking. All administrative, financial, and payroll modules are automatically hidden from the navigation bar.

Focused Workspace: Non-admin employees see only Dashboard, Recruitment Suite (Jobs, My Candidates, Matching, Pool, Pipeline, Interviews, Referrals), and Leaves.

4.2 Assigned Candidates Workspace (/pages/my-candidates.html)

Recruiter Candidate Workspace Employee Role

Recruiters can view and manage candidate profiles assigned to them by administrators. Tracks candidate communication notes, interview schedules, and placement progression.

Recruiter Actions:

  • + Add Candidate: Register a new job seeker with contact details and medical specialty.
  • Schedule Interview: Assign candidate to an open hospital job vacancy and set interview date/time.
  • Add Note: Record recruiter call notes, salary expectations, and availability date.

4.3 Submitting & Tracking Leave Requests (/pages/leaves.html)

Employee Leave Application Guide Employee Role

Employees can request leaves of absence and monitor approval status in real time. The dashboard displays remaining leave balances across Sick, Casual, Paid, and Emergency leaves.

Step-by-Step Leave Submission:

  1. Navigate to **HR → Leaves** in the sidebar.
  2. Click + Apply for Leave at top right.
  3. Select **Leave Type** (Sick Leave, Casual Leave, Paid Leave, Emergency Leave).
  4. Select **Start Date** and **End Date**.
  5. Enter a clear **Reason** (e.g. Family emergency, Medical checkup).
  6. Click Submit Request.
  7. The request is logged with status PENDING and sent to Admin for review. Once approved, the status updates to APPROVED.

SECTION 5: Operating Workflows & Troubleshooting Guide

5.1 Common Troubleshooting Solutions

Symptom / Error Message Root Cause Resolution
"Failed to create leave request" Database column mismatch or date arithmetic syntax error Resolved in v1.0.0. Database auto-runs migrations on startup.
"Failed to create salary record" MySQL-specific syntax in embedded database mode Resolved in v1.0.0. System uses cross-database upsert logic.
"Access Denied / Redirect to Dashboard" Employee attempting to open restricted Admin or Finance page Security rule enforced by auth.js and sidebar.js.
"Invoice number already exists" Duplicate manual invoice number entry System auto-generates timestamped unique numbers (INV-YYYY-XXXX).
